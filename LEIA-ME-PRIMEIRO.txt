MINHA COMUNIDADE — PACOTE COM REACT + API CONECTADOS

Conteúdo:
- react-minha-comunidade: seu React atualizado para usar Axios e a API.
- api-meu-bairro: API organizada em controller/service/repository.

PASSOS:
1) Confira o arquivo api-meu-bairro/GUIA-INSTALACAO.md.
2) Se o banco já existia da versão anterior, execute uma vez api-meu-bairro/migracao_coordenadas.sql no MySQL Workbench.
3) No terminal do VS Code, entre na pasta api-meu-bairro, rode npm install e depois npm run dev.
4) Em outro terminal, entre em react-minha-comunidade, rode npm install e depois npm start.
5) A API fica na porta 5000 e o React usa http://localhost:5000/api.

Importante:
- O projeto usa o bairro de demonstração com id 1.
- Problemas e sugestões são enviados para o banco de dados; login/cadastro também usam a API.
- O mapa mostra registros cujos endereços foram geocodificados com sucesso. Endereços fictícios ou incompletos podem não aparecer como marcadores.
- O pacote não inclui node_modules nem a pasta .git, para reduzir bastante o tamanho. npm install instala as dependências novamente.
